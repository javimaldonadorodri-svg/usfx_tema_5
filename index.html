📐 TEMA 5: MÁXIMO COMÚN DIVISOR Y MÍNIMO COMÚN MÚLTIPLO

5.1 Definición de máximo común divisor

El máximo común divisor (M.C.D.) de dos o más expresiones algebraicas (polinomios), es la expresión algebraica de mayor coeficiente numérico y de mayor grado que está contenida exactamente en cada una de ellas.

5.3 Definición de mínimo común múltiplo

El mínimo común múltiplo (m.c.m.) de dos o más expresiones algebraicas es la expresión algebraica de menor coeficiente numérico y de menor grado que es divisible exactamente por cada una de las expresiones dadas.

Se halla el m.c.m., de los coeficientes y a continuación de este se escriben todas las letras distintas, sean o no sean comunes, dando a cada letra el mayor exponente que tenga en las expresiones dadas.

📌 Recordatorio

  • M.C.D. → factores comunes con menor exponente.
  • m.c.m. → factores comunes y no comunes con mayor exponente.

5.2.1 Máximo común divisor de monomios

Procedimiento:

  • • Se encuentra el M.C.D. de la parte numérica, realizando la descomposición en sus factores primos.
  • • Se encuentra el M.C.D. de la parte literal, buscando letras comunes de menor exponente.
📘 Ejemplo a)
El M.C.D. de la expresión 84x⁵y²z⁶ ; 126x³y⁴w⁵ es:
= 2²·3·7·x⁵y²z⁶   ;   2·3²·7·x³y⁴w⁵
M.C.D. = 2·3·7·x³y² = 42x³y²
📘 Ejemplo b)
El M.C.D. de la expresión −2ab ; 4mn² ; 3amx es:
M.C.D. = 1 (no tienen factores comunes)
📘 Ejemplo c)
El M.C.D. de la expresión 160a⁷b³c² ; 192b⁶c⁴d ; 48ab⁴c es:
= 2⁵·5·a⁷b³c²   ;   2⁶·3·b⁶c⁴d   ;   2⁴·3·a·b⁴c
M.C.D. = 2⁴·b³·c = 16b³c

✏️ Ejercicios — MCD de monomios

Hallar el M.C.D. de: 15a²b³c  ;  12ab²x  ;  36b⁴cy
M.C.D. = 3b²c
Hallar el M.C.D. de: 50m⁴y⁵z²  ;  45m²y³z⁶  ;  70m³y⁴z⁴
M.C.D. = 5m²y³z²
Hallar el M.C.D. de: 8x²(y−1)  ;  12x(y−1)²
M.C.D. = 4x(y−1)
Hallar el M.C.D. de: 4m²n  ;  8m³n²  ;  2cm²n  ;  10c²mn³
M.C.D. = 2mn
Hallar el M.C.D. de: 36a²b⁴  ;  48a³b⁸c  ;  60a⁴b⁸m
M.C.D. = 12a²b⁴

5.2.2 Máximo común divisor de polinomios

Procedimiento:

  • • Se debe expresar en productos por medio de la descomposición de factores (casos de factorización).
  • • Se encuentra el M.C.D. de los coeficientes como en aritmética, de la parte literal, de los factores simples y compuestos solo lo común y con menor exponente.
📘 Ejemplo a)
Hallar el M.C.D. de: 3x²+3x−60  ;  6x²−18x−24
= 3(x²+x−20)  ;  6(x²−3x−4)
= 3(x+5)(x−4)  ;  2·3(x−4)(x+1)
M.C.D. = 3(x−4)
📘 Ejemplo b)
Hallar el M.C.D. de: 4m²−n²  ;  8m³+n³  ;  4m²+4mn+n²
= (2m−n)(2m+n)  ;  (2m+n)(4m²−2mn+n²)  ;  (2m+n)²
M.C.D. = (2m+n)
📘 Ejemplo c)
Hallar el M.C.D. de: 6p+6q  ;  5p²+10pq+5q²  ;  7p²−7q²
= 6(p+q)  ;  5(p+q)²  ;  7(p+q)(p−q)
M.C.D. = (p+q)

✏️ Ejercicios — MCD de polinomios

Hallar el M.C.D. de: 2x³−2x²  ;  3x²−3x  ;  4x³−4x²
M.C.D. = x(x−1)
Hallar el M.C.D. de: 2x³+4x²−16x  ;  16(x²−4)  ;  x²−7x+10
M.C.D. = (x−2)
Hallar el M.C.D. de: 2a²+2ab  ;  4a⁴−4a²b²
M.C.D. = 2a(a+b)
Hallar el M.C.D. de: 4m²+8m−12  ;  2m²−6m+4  ;  6m²+18m−24
M.C.D. = 2(m−1)
Hallar el M.C.D. de: 3a²+6ab+3b²  ;  4a²−b²  ;  a²+4ab+4b²
M.C.D. = (a+b)

5.4.1 Mínimo común múltiplo de monomios

Procedimiento:

  • • Se encuentra el m.c.m. de la parte numérica, realizando la descomposición en sus factores primos.
  • • Se encuentra el m.c.m. de los coeficientes como en aritmética, de la parte literal, de los factores simples y compuestos los comunes y no comunes con mayor exponente.
📘 Ejemplo a)
El m.c.m. de la expresión 42a²bc ; 21a²b²m ; 15a⁵x es:
= 2·3·7·a²bc  ;  3·7·a²b²m  ;  3·5·a⁵x
m.c.m. = 2·3·7·5·a⁵·b²·c·m·x = 210a⁵b²cmx
📘 Ejemplo b)
El m.c.m. de la expresión 15mn² ; 10m² ; 20n³ ; 25mn⁴ es:
= 3·5·mn²  ;  2·5·m²  ;  2²·5·n³  ;  5²·mn⁴
m.c.m. = 3·5²·2²·m²·n⁴ = 300m²n⁴
📘 Ejemplo c)
El m.c.m. de la expresión 4m(x−1) ; 2a(x−1)² ; 6m²(x−1)³ es:
= 2²·m·(x−1)  ;  2·a·(x−1)²  ;  2·3·m²·(x−1)³
m.c.m. = 2²·3·a·m²·(x−1)³ = 12am²(x−1)³

✏️ Ejercicios — mcm de monomios

Hallar el m.c.m. de: 25a³bc⁷  ;  10ab²m
m.c.m. = 50a³b²c⁷m
Hallar el m.c.m. de: 8x²(m−n)  ;  12x(m−n)²
m.c.m. = 24x²(m−n)²
Hallar el m.c.m. de: 60x²y⁷z  ;  100x³z⁴  ;  85yz⁵
m.c.m. = 5100x³y⁷z⁵
Hallar el m.c.m. de: 4a(b−2)(b+2)  ;  6a²(b+2)²
m.c.m. = 12a²(b−2)(b+2)²
Hallar el m.c.m. de: 3ax  ;  2mn  ;  7by
m.c.m. = 42axmnby

5.4.2 Mínimo común múltiplo de polinomios

Procedimiento:

  • • Se debe expresar en productos por medio de la descomposición de factores (casos de factorización).
  • • Se encuentra el m.c.m. de los coeficientes como en aritmética, de la parte literal, de los factores simples y compuestos, lo común y no común con mayor exponente.
📘 Ejemplo a)
Hallar el m.c.m. de: 12x³−36x²−48x  ;  8x⁴−8x²
= 12x(x²−3x−4)  ;  8x²(x²−1)
= 2²·3·x·(x−4)(x+1)  ;  2³·x²·(x−1)(x+1)
m.c.m. = 2³·3·x²·(x−4)(x+1)(x−1) = 24x²(x−4)(x+1)(x−1)
📘 Ejemplo b)
Hallar el m.c.m. de: 5a³y² − 5b³y²  ;  15a²y² − 30aby² + 15b²y²
= 5y²(a³ − b³)  ;  15y²(a² − 2ab + b²)
= 5y²(a − b)(a² + ab + b²)  ;  3·5y²(a − b)²
m.c.m. = 15y²(a − b)²(a² + ab + b²)
📘 Ejemplo c)
Hallar el m.c.m. de: x³ − 9x + 5x² − 45  ;  x⁴ + 2x³ − 15x²
= (x³ − 9x) + (5x² − 45)  ;  x²(x² + 2x − 15)
= x(x² − 9) + 5(x² − 9)  ;  x²(x + 5)(x − 3)
= (x² − 9)(x + 5)  ;  x²(x + 5)(x − 3)
= (x − 3)(x + 3)(x + 5)  ;  x²(x + 5)(x − 3)
m.c.m. = x²(x − 3)(x + 3)(x + 5)

✏️ Ejercicios — mcm de polinomios

Hallar el m.c.m. de: 12m + 12  ;  42m − 42
m.c.m. = 84(m + 1)(m − 1) = 84(m² − 1)
Hallar el m.c.m. de: 8n² − 10n − 3  ;  20n² + 13n + 2  ;  10n² − 11n − 6
m.c.m. = (4n+1)(2n−3)(5n+2)(2n+1)
Hallar el m.c.m. de: a³ − 27b³  ;  a² − 9b²  ;  a² − 6ab + 9b²  ;  a² + 3ab + 9b²
m.c.m. = (a − 3b)²(a + 3b)(a² + 3ab + 9b²)
Hallar el m.c.m. de: p³ + q³  ;  (p + q)³
m.c.m. = (p + q)³(p² − pq + q²)
Hallar el m.c.m. de: x² + 2x  ;  x³ − 2x²  ;  x² − 4
m.c.m. = x²(x + 2)(x − 2) = x²(x² − 4)

📌 Nota importante

El m.c.m. de polinomios se obtiene multiplicando todos los factores comunes y no comunes con su mayor exponente. Siempre factorizar completamente primero.
