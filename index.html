📐 TEMA 5: MCD y mcm

5.1 Definición de máximo común divisor

El máximo común divisor (M.C.D.) de dos o más expresiones algebraicas (polinomios), es la expresión algebraica de mayor coeficiente numérico y de mayor grado que está contenida exactamente en cada una de ellas.

5.3 Definición de mínimo común múltiplo

El mínimo común múltiplo (m.c.m.) de dos o más expresiones algebraicas es la expresión algebraica de menor coeficiente numérico y de menor grado que es divisible exactamente por cada una de las expresiones dadas.

📌 Recordatorio

  • M.C.D. → factores comunes con menor exponente.
  • m.c.m. → factores comunes y no comunes con mayor exponente.

5.2.1 MCD de Monomios

Procedimiento:

  • • Se encuentra el M.C.D. de la parte numérica (descomposición en factores primos).
  • • Se encuentra el M.C.D. de la parte literal (letras comunes con menor exponente).
📘 Ejemplo a)
84x⁵y²z⁶ ; 126x³y⁴w⁵
= 2²·3·7·x⁵y²z⁶ ; 2·3²·7·x³y⁴w⁵
M.C.D. = 2·3·7·x³y² = 42x³y²
📘 Ejemplo b)
−2ab ; 4mn² ; 3amx
M.C.D. = 1 (sin factores comunes)
📘 Ejemplo c)
160a⁷b³c² ; 192b⁶c⁴d ; 48ab⁴c
= 2⁵·5·a⁷b³c² ; 2⁶·3·b⁶c⁴d ; 2⁴·3·a·b⁴c
M.C.D. = 2⁴·b³·c = 16b³c

✏️ Ejercicios - MCD de Monomios

a) 15a²b³c ; 12ab²x ; 36b⁴cy
M.C.D. = 3b²c
b) 50m⁴y⁵z² ; 45m²y³z⁶ ; 70m³y⁴z⁴
M.C.D. = 5m²y³z²
c) 8x²(y−1) ; 12x(y−1)²
M.C.D. = 4x(y−1)
d) 4m²n ; 8m³n² ; 2cm²n ; 10c²mn³
M.C.D. = 2mn
e) 36a²b⁴ ; 48a³b⁸c ; 60a⁴b⁸m
M.C.D. = 12a²b⁴

5.2.2 MCD de Polinomios

Procedimiento:

  • • Expresar en productos mediante factorización (casos de factorización).
  • • M.C.D. de coeficientes (como en aritmética).
  • • Factores comunes (simples y compuestos) con menor exponente.
📘 Ejemplo a)
3x²+3x−60 ; 6x²−18x−24
= 3(x²+x−20) ; 6(x²−3x−4)
= 3(x+5)(x−4) ; 2·3(x−4)(x+1)
M.C.D. = 3(x−4)
📘 Ejemplo b)
4m²−n² ; 8m³+n³ ; 4m²+4mn+n²
= (2m−n)(2m+n) ; (2m+n)(4m²−2mn+n²) ; (2m+n)²
M.C.D. = (2m+n)
📘 Ejemplo c)
6p+6q ; 5p²+10pq+5q² ; 7p²−7q²
= 6(p+q) ; 5(p+q)² ; 7(p+q)(p−q)
M.C.D. = (p+q)

✏️ Ejercicios - MCD de Polinomios

a) 2x³−2x² ; 3x²−3x ; 4x³−4x²
M.C.D. = x(x−1)
b) 2x³+4x²−16x ; 16(x²−4) ; x²−7x+10
M.C.D. = (x−2)
c) 2a²+2ab ; 4a⁴−4a²b²
M.C.D. = 2a(a+b)
d) 4m²+8m−12 ; 2m²−6m+4 ; 6m²+18m−24
M.C.D. = 2(m−1)
e) 3a²+6ab+3b² ; 4a²−b² ; a²+4ab+4b²
M.C.D. = (a+b)

5.4.1 mcm de Monomios

Procedimiento:

  • • Se encuentra el m.c.m. de la parte numérica (descomposición en factores primos).
  • • Factores comunes y no comunes con mayor exponente.
📘 Ejemplo a)
42a²bc ; 21a²b²m ; 15a⁵x
= 2·3·7·a²bc ; 3·7·a²b²m ; 3·5·a⁵x
m.c.m. = 2·3·7·5·a⁵·b²·c·m·x = 210a⁵b²cmx
📘 Ejemplo b)
15mn² ; 10m² ; 20n³ ; 25mn⁴
= 3·5·mn² ; 2·5·m² ; 2²·5·n³ ; 5²·mn⁴
m.c.m. = 3·5²·2²·m²·n⁴ = 300m²n⁴
📘 Ejemplo c)
4m(x−1) ; 2a(x−1)² ; 6m²(x−1)³
= 2²·m·(x−1) ; 2·a·(x−1)² ; 2·3·m²·(x−1)³
m.c.m. = 2²·3·a·m²·(x−1)³ = 12am²(x−1)³

✏️ Ejercicios - mcm de Monomios

a) 25a³bc⁷ ; 10ab²m
m.c.m. = 50a³b²c⁷m
b) 8x²(m−n) ; 12x(m−n)²
m.c.m. = 24x²(m−n)²
c) 60x²y⁷z ; 100x³z⁴ ; 85yz⁵
m.c.m. = 5100x³y⁷z⁵
d) 4a(b−2)(b+2) ; 6a²(b+2)²
m.c.m. = 12a²(b−2)(b+2)²
e) 3ax ; 2mn ; 7by
m.c.m. = 42axmnby

5.4.2 mcm de Polinomios

Procedimiento:

  • • Expresar en productos mediante factorización.
  • • m.c.m. de coeficientes (como en aritmética).
  • • Factores comunes y no comunes con mayor exponente.
📘 Ejemplo
12x³−36x²−48x ; 8x⁴−8x²
= 12x(x²−3x−4) ; 8x²(x²−1)
= 2²·3·x·(x−4)(x+1) ; 2³·x²·(x−1)(x+1)
m.c.m. = 2³·3·x²·(x−4)(x+1)(x−1) = 24x²(x−4)(x+1)(x−1)

📌 Nota importante

El m.c.m. de polinomios se obtiene multiplicando todos los factores comunes y no comunes con su mayor exponente. Siempre factorizar completamente primero.
